# Content and source policy / 内容与来源政策

## Public-content boundary / 公开内容边界

This site publishes user-facing HIA-uView guidance, component references, documented compatibility evidence, release notes, migration guidance, and license/notice links. It does not publish private planning, audit workpapers, developer-machine paths, temporary package artifacts, credentials, AppIDs, analytics data, internal screenshots, or unreviewed source material.

本站发布面向使用者的 HIA-uView 指引、组件 reference、已记录的兼容性证据、版本说明、迁移指引和许可证/NOTICE 链接。它不发布私有规划、审计工作底稿、开发机路径、临时包产物、凭据、AppID、统计数据、内部截图或未审阅源码材料。

## Bilingual publication / 双语发布

Every public content id has a complete `zh-Hans` page and a complete `en` page. Navigation, status, warnings, release scope, and migration limits must be equivalent in both locales. A missing translation blocks publication rather than falling back silently to the other locale.

每个公开内容 id 都有完整的 `zh-Hans` 页面和完整的 `en` 页面。导航、状态、警告、版本范围和迁移限制必须在两个语言中等价。缺少翻译会阻断发布，不能静默回退到另一语言。

## Upstream relationship / 上游关系

HIA-uView uses familiar `u-*` template names and `U*` exports for currently implemented components to reduce the migration barrier for uView-family users. It is not a complete upstream fork and does not promise API, plugin, theme, application, or release compatibility with any upstream project.

HIA-uView 为当前已实现组件使用熟悉的 `u-*` 模板名称和 `U*` 导出，以降低 uView 系列使用者的迁移障碍。它不是完整上游 fork，也不承诺与任一上游项目的 API、plugin、主题、应用或 release 兼容性。

The site may link to upstream repositories and attribute their relationship when the linked material is public and relevant. It must not copy upstream source, text, screenshots, images, logos, trademarks, page layouts, CSS, statistics, or claims. Any actual source reuse remains subject to HIA-uView’s file-by-file source-intake, license, and NOTICE process in its own repository.

本站可在链接材料公开且相关时链接上游仓库并说明其关系。它不得复制上游源码、文案、截图、图片、logo、商标、页面布局、CSS、统计数据或主张。任何实际源码复用仍须在 HIA-uView 自身仓库中遵守逐文件来源 intake、许可证和 NOTICE 流程。

## Theme and accessibility / 主题与无障碍

Cobalt blue `#0047AB` is the structural and primary-action color. Clear cyan `#00A8D3` is reserved for local emphasis, progress, and data highlights; cyan backgrounds require dark text and icons. Color is never the only state signal.

钴蓝 `#0047AB` 是结构和主要行动色。清透青 `#00A8D3` 保留给局部强调、进度和数据高亮；清透青背景必须使用深色文字和图标。颜色绝不能是唯一状态信号。

The future site must prove keyboard navigation, focus visibility, responsive behavior, contrast, and localized content before claiming them. Current policy does not constitute WCAG conformance, production deployment, device testing, or performance certification.

未来站点必须在实际证明键盘导航、focus 可见性、响应式行为、对比度和本地化内容后才可声明它们。当前政策不构成 WCAG 合规、生产部署、设备测试或性能认证。
